shop-storefront — дев-роутер

Страницы рендерятся liquidjs из templates/ с моками mock/. Реальные пути витрины тоже работают.

  • Каталог — /?mock=catalog (чипы: &cat=ceramics, страницы: &page=2)
  • Товар (найден) — /?mock=product; не найден
  • Чекаут (гость) — /?mock=checkout; member; пустая
  • Корзина (список гостя) — /?mock=cart
  • Заказ принят — /?mock=order; оплачен; не найден
  • 404 — /?mock=404 (любой несовпавший путь)

API корзины эмулируется в памяти: GET/POST /api/cart, POST /api/checkout (сабмит формы ведёт на /order/dev-order-1). Режим member: кука dev_member=1.
